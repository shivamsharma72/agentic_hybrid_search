TROUBLESHOOTING
---------------

If SSH test fails:
    ssh -T git@github.com
    # Should say: "Hi shivamsharma72! You've successfully authenticated"

If push fails with "remote already exists":
    git remote remove origin
    git remote add origin git@github.com:shivamsharma72/agentic_hybrid_search.git

If large files are being committed:
    # Check .gitignore exists
    cat .gitignore | grep parquet
    
    # Remove from staging
    git reset HEAD *.parquet
    
    # Re-add only tracked files
    git add .
