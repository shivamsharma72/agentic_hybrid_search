cd review_data_to_postgres/scripts
python3 load_reviews_to_postgres_optimized.py

------------
1. Drops 8 indexes (keeps primary key)
2. Drops foreign key constraint
3. Loads 37.5M reviews in 10 batches
4. Recreates 8 indexes
5. Recreates foreign key constraint
6. Runs ANALYZE to update statistics

STEP 5: VERIFY LOADED DATA
================================================================================

Run verification queries to ensure data was loaded correctly.

Commands:
---------
psql -d amazon_electronics_rag

Then run:

-- Check total count
SELECT COUNT(*) FROM reviews;
-- Expected: 37510000

-- Check unique users
SELECT COUNT(DISTINCT user_id) FROM reviews;
-- Expected: 16618885

-- Check unique products
SELECT COUNT(DISTINCT parent_asin) FROM reviews;
-- Expected: 348228

-- Check verified purchases
SELECT 
    COUNT(*) FILTER (WHERE verified_purchase = TRUE) as verified,
    ROUND(COUNT(*) FILTER (WHERE verified_purchase = TRUE)::numeric / COUNT(*) * 100, 1) as pct
FROM reviews;
-- Expected: 92.5%

-- Check indexes
SELECT indexname FROM pg_indexes WHERE tablename = 'reviews' ORDER BY indexname;
-- Expected: 9 indexes

-- Check foreign key
SELECT conname FROM pg_constraint WHERE conrelid = 'reviews'::regclass AND contype = 'f';
-- Expected: fk_reviews_parent_asin

-- Check table size
SELECT pg_size_pretty(pg_total_relation_size('reviews')) as total_size;
-- Expected: ~21 GB

Time: < 1 minute

================================================================================
TROUBLESHOOTING
================================================================================

If something fails:

1. Check logs: The script prints detailed error messages

2. Check disk space:
   df -h
   (Need at least 25 GB free)

3. Check database connection:
   psql -d amazon_electronics_rag -c "SELECT version();"

4. Check if table exists:
   psql -d amazon_electronics_rag -c "\dt reviews"

5. If loading fails mid-way:
   - Clear partial data: TRUNCATE TABLE reviews CASCADE;
   - Re-run: python3 load_reviews_to_postgres_optimized.py

6. See TROUBLESHOOTING.md for more solutions
