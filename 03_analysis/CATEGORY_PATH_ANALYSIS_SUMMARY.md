1. **"Laptop" in category path ≠ Actual laptop**

   - "Traditional Laptops" only has 4,862 products
   - Ratio: 4.3:1 (accessories vs actual laptops)

2. **"Cases" is the #1 leaf category**

   - 20,168 products end in "Cases"
   - These are NOT laptops, just accessories

3. **Most Specific Laptop Category:**
   - Leaf category: "Traditional Laptops"
   - Path: `Electronics > Computers & Accessories > Computers & Tablets > Laptops > Traditional Laptops`
   - Count: **4,862 products**
   - This is the cleanest laptop filter!

## 🎯 **Recommendations for Laptop Filtering**

### **Option 1: Use Exact Leaf Category (Highest Precision)**

```sql
SELECT * FROM products
WHERE
    'Traditional Laptops' = ANY(categories);
```

**Expected Result:** ~4,862 laptops  
**Precision:** ~98%  
**Recall:** ~40% (misses chromebooks, 2-in-1s, gaming laptops)

---

### **Option 2: Use Multiple Leaf Categories (Better Recall)**

```sql
SELECT * FROM products
WHERE
    'Traditional Laptops' = ANY(categories)
    OR '2 in 1 Laptops' = ANY(categories)
    OR 'Chromebooks' = ANY(categories)
    OR 'Gaming Laptops' = ANY(categories);
```

**Expected Result:** ~7,000-10,000 laptops  
**Precision:** ~95%  
**Recall:** ~60-70%

---

### **Option 3: Contains "Laptops" AND Exclude Accessories (Balanced)**

```sql
SELECT * FROM products
WHERE
    EXISTS (SELECT 1 FROM unnest(categories) AS cat
            WHERE cat ILIKE '%laptop%')
    AND NOT EXISTS (SELECT 1 FROM unnest(categories) AS cat
                    WHERE cat ILIKE '%accessories%')
    AND NOT EXISTS (SELECT 1 FROM unnest(categories) AS cat
                    WHERE cat IN ('Cases', 'Bags', 'Sleeves', 'Stands', 'Batteries', 'Chargers'));
```

**Expected Result:** ~8,000-12,000 laptops  
**Precision:** ~90-92%  
**Recall:** ~70-75%

---

### **Option 4: Combine with Details (Highest Confidence) - RECOMMENDED ✅**

```sql
SELECT * FROM products
WHERE
    -- Has laptop in category path
    EXISTS (SELECT 1 FROM unnest(categories) AS cat
            WHERE cat ILIKE '%laptop%')

    -- Exclude accessories
    AND NOT EXISTS (SELECT 1 FROM unnest(categories) AS cat
                    WHERE cat IN ('Cases', 'Bags', 'Sleeves', 'Stands',
                                  'Batteries', 'Chargers', 'Adapters'))

    -- Validate with specs in details
    AND (
        details->>'RAM' IS NOT NULL
        OR details->>'Processor' IS NOT NULL
        OR details->>'Screen Size' IS NOT NULL
    );
```

**Expected Result:** ~12,000 laptops (matches our previous analysis!)  
**Precision:** ~95-98%  
**Recall:** ~65-70%  
**This is what we already implemented!** ✅
